# Organizador de archivos

Script en Python que ordena automáticamente una carpeta desordenada,
moviendo cada archivo a su subcarpeta según el tipo
(Imágenes, Documentos, Presentaciones, Excel, Audio, Videos).

## Cómo usarlo
1. Coloca el script junto a la carpeta que quieres ordenar
2. Ejecuta: python organizador.py
